## 🎮 Sitecom Games - SENAI SP

Projeto web desenvolvido como atividade acadêmica no SENAI SP, com foco em construção de interface e interatividade utilizando tecnologias front-end.

# 🎯 Objetivo

Desenvolver uma aplicação web simples com páginas interativas, praticando conceitos de estruturação HTML, estilização com CSS e lógica básica com JavaScript.

# 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

# 📁 Estrutura do projeto

- index.html → Página principal do site
- login.html → Página de login
- css/ → Arquivos de estilização
- js/ → Scripts de interação
- img/ → Imagens do projeto

# 🚀 Como executar

- Clone o repositório: git clone https://github.com/Devmoises79/Sitecom-Games-SENAISP.git
* Abra o arquivo index.html no navegador

# 📌 Observação

- Este projeto foi desenvolvido como atividade acadêmica para prática de desenvolvimento web front-end.
